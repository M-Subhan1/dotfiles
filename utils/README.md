# utils

Small standalone tools. Each folder is self-contained and has its own README and installer, so you can copy just one folder.

| Util | What it does |
|---|---|
| [skif-tim-g9-wifi-login](skif-tim-g9-wifi-login/) | Stops the SKIF guest Wi-Fi at Tim Hortons G-9 from logging you out every hour (macOS) |
